# 🎮 Unity 3D シミュレーター 開発ログ & ナレッジベース

## 1. プロジェクトおよび学習者の基本方針
- **目標**: デスクトップベースの3Dシミュレーション（および最終的なVRアプリケーション）をUnityで構築・運用する。
- **学習スタイル**: 1日1時間程度。理論だけでなくハンズオン・体験重視。
- **開発環境**:
  - **ゲームエンジン**: Unity (Universal 3D テンプレート / 日本語化パッケージ適用済み)
  - **コードエディタ**: Visual Studio Community / Visual Studio Code
  - **バージョン管理**: Git / GitHub / GitHub Desktop (Publicリポジトリ)
  - **入力システム**: Hybrid モード (`Input Manager` & `New Input System` 併用設定)
- **プロジェクト管理・整理方針**:
  - `Assets/Scripts` フォルダを作成し、全C#スクリプトを一元管理。
  - ワールドの基準（原点）を意識し、オブジェクトの座標・サイズを最適化。
  - `.gitignore`（Unity用設定）を用いて不要な一時キャッシュファイルを除外。

## 2. これまでに達成した進捗状況

### 1️⃣ 開発環境の構築 & バージョン管理（Git / GitHub）
- **環境設定**:
  - Universal 3D プロジェクトの新規作成および Unity インターフェースの日本語化。
  - `Ctrl + S` によるシーン上書き保存手順の定着。
- **バージョン管理の導入**:
  - **GitHub / GitHub Desktop** の導入と初期セットアップ。
  - `.gitignore` に **`Unity`** を指定し、巨大な一時ファイル（Library等）を除外してコードとアセットのみを軽量管理。
  - ブランチ運用（`main` からの `feature/door` や `feature/notes` 等の機能別枝分かれ）の概念把握。
  - リポジトリの Public (全体公開) 設定および `README.md` による学習ログ自動表示の構築。
  - GitHub Desktop を使用した「コミット（セーブ）」と「プッシュ（クラウド保存）」の習得。

### 2️⃣ 3D空間構築とオブジェクト操作
- **基本操作**:
  - 4大ウィンドウ（ヒエラルキー、シーン、インスペクター、プロジェクト）の役割理解。
  - 基本3Dオブジェクト（Cube, Plane, Sphere, Capsule, Cylinder）の配置と拡大縮小・回転操作。
  - Transform のリセット機能や `F` キー（Focus）によるカメラ迷子解消。
  - 拡大縮小時の「鎖マーク（縦横比固定）」の使い分け。
  - 床オブジェクト（Position Y: `-0.25`）やプレイヤーの高さ・配置を最適化し、めり込みや切り欠けを防止。
- **マテリアルとアセット管理**:
  - マテリアルの新規作成、Base Map（色）、Metallic（金属感）、Smoothness（滑らかさ）の調整とドラッグ＆ドロップ適用。
  - アセット増加を見越したフォルダ分け管理の徹底。

### 3️⃣ 1人称視点プレイヤーの実装 (`PlayerController.cs`)
- **視点移動（カメラ操作）**:
  - 右クリック押下中にマウス移動（`Input.GetAxis("Mouse X/Y")`）で自由な視点回転を実装。
  - 上下視点を `-80°` ～ `80°` に `Mathf.Clamp` で制限し、不自然な回転を防止。
  - 視点操作中は `Cursor.lockState = CursorLockMode.Locked` でカーソルを画面中央に固定。
- **移動 & ジャンプ物理制御**:
  - `WASD` キー入力（`Input.GetAxis("Horizontal/Vertical")`）を取得し、`transform.Translate` で移動。
  - `Rigidbody` と `OnCollisionEnter` を使った接地判定（`isGrounded`）。
  - スペースキー押下時に `AddForce(Vector3.up * jumpForce, ForceMode.Impulse)` で物理ジャンプを実行。

### 4️⃣ レイキャスト（Raycast）によるギミック & 物理相互作用
- 画面中央（カメラ正面）から見えない光線（Ray）を照射（射程: 5m）。
- **ドアの開閉インタラクション**:
  - ヒットしたオブジェクトに `Door` コンポーネントが付与されているか検出。
  - ドアが存在すれば `door.ToggleDoor()` を呼び出して即座に開閉。
- **物理吹き飛ばし**:
  - 対象がドアでない場合、`Rigidbody` の有無を確認し `AddForce` で奥へ弾き飛ばす。

### 5️⃣ ドアの開閉スクリプト機能 (`Door.cs`)
- 内部フラグ（`isOpen`）でドアの状態（開・閉）を管理。
- 呼び出しごとに状態を反転させ、`transform.rotation = Quaternion.Euler(...)` でY軸を90度回転させてパカッと開閉させる仕掛けを構築。

### 6️⃣ 物理演算と当たり判定の理論理解
- **Collider（コライダー）**: 透明なバリア。実体としての衝突・壁抜け防止。
- **Rigidbody（リジッドボディ）**: 重力・質量・物理衝突の自動計算エンジン。
- **Is Trigger（トリガー）**: あえてすり抜けさせ、エリア侵入検知などに使用する判定。

## 4. Unity & Git クイックリファレンス（操作マニュアル）

### ■ 主要ウィンドウ
- **ヒエラルキー (Hierarchy)**: 画面上のオブジェクト一覧。
- **シーン (Scene)**: 3D空間の作業画面。
- **インスペクター (Inspector)**: 選択したオブジェクトの詳細設定（Transform, Material等）。
- **プロジェクト (Project)**: 素材（マテリアル、スクリプト、画像等）の保管庫。

### ■ ショートカット・操作一覧
- **`W` / `E` / `R` / `Q`**: 移動 / 回転 / 拡大縮小 / 視点移動ツール切替
- **`F` キー**: 選択したオブジェクトへカメラを即座にフォーカス（迷子復帰）
- **`Ctrl + Z`**: 元に戻す（Undo）
- **`Ctrl + S`**: シーンおよびプロジェクトの保存
- **MonoBehaviour スクリプト**: Project右クリック ＞ 「作成」 ＞ 「MonoBehaviour スクリプト」 でC#ファイル作成

### ■ GitHub Desktop 操作フロー
1. **変更の確認**: ファイル変更時、左側 `Changes` タブに自動反映。
2. **Commit（ローカルセーブ）**: 左下にタイトル（Summary）を入力し `Commit to main` を押す。
3. **Push（クラウド保存）**: 画面上部の `Push origin` を押して GitHub 上へアップロード。
4. **ブラウザ確認**: `View on GitHub` ボタンでWeb上のリポジトリを開く。
